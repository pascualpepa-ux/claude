# Logo y piezas de YouTube de Rumbo Traveling

| Archivo | Para qué |
|---|---|
| `rumbo-logo-completo-oliva.svg` / `-crema.svg` | Logo completo en vector, sirve para cualquier tamaño (crema = sobre fondos oscuros) |
| `rumbo-isotipo-oliva.svg` / `-crema.svg` | Solo la R con el avión, en vector |
| `rumbo-logo-completo-oliva-4000.png` / `-crema-4000.png` | Logo completo en PNG de 4000 px, fondo transparente |
| `rumbo-isotipo-oliva-3000.png` / `-crema-3000.png` | Isotipo en PNG de 3000 px, fondo transparente |
| `youtube-perfil-800.png` / `-2048.png` | Foto de perfil del canal (YouTube la recorta en círculo) |
| `youtube-banner-es.png` / `-en.png` | Banner del canal, 2560×1440 |
| `youtube-banner-zonas-segura.png` | El mismo banner con la zona que se ve en todos los dispositivos marcada (solo de guía) |
| `youtube-descripcion.md` | Descripción del canal y del primer Short, en español e inglés |

Los vectores salen de `trazado.svg`, que es el logo original (`original-logo.jpg`) vectorizado con VTracer. El color oliva es `#575b40` y el crema `#f2ecdc`, los mismos de la web.
